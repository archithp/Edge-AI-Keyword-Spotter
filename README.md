# Edge-AI-Keyword-Spotter
Developing a real-time wake-word detection system on ESP32-S3 using FreeRTOS and TFLite Micro for on-device Edge AI inference. Implementing an audio processing pipeline with I2S microphone interfacing, MFCC feature extraction, and TinyML-based keyword spotting. Integrating MQTT-based IoT event triggering real-time operation.
